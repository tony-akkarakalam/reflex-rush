# ⚡ Reflex Rush

A simple reaction speed testing game built using HTML, CSS, and JavaScript.

## How to Play

1. Click Start Game.
2. Wait for the red box to turn green.
3. Click as fast as possible.
4. Try to beat your best score.

## Features

- Randomized wait time
- Reaction time measurement
- Personal best tracking
- Local storage support
- Simple and responsive UI

## Technologies

- HTML
- CSS
- JavaScript
